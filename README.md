# gunin-iot.github.io
Trainee
Основний канал: Високошвидкісне дротове підключення (Оптоволокно / Ethernet).

Резервний канал: Мобільна мережа (4G/LTE або 5G), яка активується через 4G-модем у маршрутизаторі при падінні основного інтернету.

Оскільки мобільний трафік часто є лімітованим, локальний сервер офісу застосовує жорсткіший QoS: під час роботи від 4G він починає буферизувати або відкидати "важку" рутинну телеметрію (щоб не перевантажити канал і не витрачати трафік), але миттєво пропускає критичні події (наприклад, спрацювання датчиків безпеки чи пожежної тривоги).

Fog-сервер (Туманні обчислення): Проміжний вузол "Локальний сервер корпусу". Дані йдуть за маршрутом: Сенсор → Edge (ESP32) → Fog-сервер → Хмара.
Гібридна маршрутизація (5G / NTN): Fog-сервер має два канали до хмари. Основний — швидкий наземний (Terrestrial). Резервний — повільніший супутниковий (NTN, наприклад Starlink), який активується при збоях.
TinyML класифікація: Edge-контролер тепер не просто "викидає" шум, він маркує пакети. Звичайні дані (білі), аномалії (помаранчеві).
Федеративне навчання (FL): Edge-вузол періодично генерує спеціальні пакети оновлення нейромережі (фіолетові), які відправляються в хмару для покращення глобальної моделі.
Store-and-Forward та QoS (Буфер): Якщо основний канал падає, Fog-сервер починає накопичувати пакети в локальний буфер. При передачі через вузький супутниковий канал (NTN), пріоритет (QoS) віддається критичним аномаліям та FL-пакетам, тоді як звичайна телеметрія може затримуватись або відкидатись.
